# Petify Frontend

Shopify Hydrogen storefront for Petify e-commerce application.

## Setup (To be completed in Phase 2)

This directory will contain:
- Product page with image upload
- AI style selector
- Preview component
- Checkout integration

## Environment Variables

Create `.env` file:

```
SHOPIFY_STOREFRONT_API_TOKEN=your-token-here
SHOPIFY_STORE_DOMAIN=your-store.myshopify.com
BACKEND_API_URL=http://localhost:3001
```

## Development

```bash
npm install
npm run dev
```

Frontend will be fully implemented in Phase 2 after Phase 1 approval.
